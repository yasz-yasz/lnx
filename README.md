# LNX by YAS

Distro Linux kustom berbasis **Ubuntu 24.04 Minimal** dengan pendekatan ringan ala **Puppy Linux (Live RAM Mode)**, tampilan desktop **Windows 11**, dukungan paket **APT, Snap, dan Flatpak**, serta installer permanen **Calamares**.

## Cara Build ISO via GitHub Actions
1. Upload isi repository ini ke GitHub.
2. Buka tab **Actions** lalu pilih **Build LNX by YAS ISO**.
3. Klik **Run workflow**, masukkan nomor versi (contoh: `1.0`), lalu tunggu ±15–25 menit.
4. Unduh file `LNX-by-YAS-1.0-amd64.iso` di tab **Releases**.
